# Modern Web Guidance Skill

This is a local copy of the modern-web-guidance SKILL.md.

## Core Methodology
- At the start of implementing any web feature, search for specific web development use cases and retrieve their corresponding best practice guides.
- Avoid implementing ad-hoc solutions or loading large dependencies unnecessarily.
- Respect prefers-reduced-motion media query.
- Use native CSS implementations of scroll-driven animations where supported, and fallback to IntersectionObserver if necessary.
